# Card Documentation

This directory contains the source Markdown for the documentation opened from
each tool card. HTML should be generated from these files for display in the
tool; these Markdown files remain the maintained source.

The current metadata-free template is in
[`../templates/card_documentation_template.md`](../templates/card_documentation_template.md).
The earlier concise and detailed templates remain in this directory for
reference.
